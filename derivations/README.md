# Derivations behind the viewer

Working reports of the OPH particle campaign (November 2026), published so that every result shown in the viewer
can be checked. Status words in the reports: EXACT (proved or computed exactly), DERIVED (follows under the named
premises), CONDITIONAL (needs named declared items), DECLARED (a stated choice), OPEN (no source construction yet),
NOT BLIND (compared with measurement after the value was known).
