# Instructions for agents working on the particles site

Owner ruling of 2026-11-17: the model derives no particle mass. Every mass value in the OPH work so far is calibrated
to a measurement, imported from the literature, set by a declared construction, or open.

- The site (particles.floatingpragma.ai, branch `gh-pages`) shows no particle masses, no matches with measured values
  and no numerical results. The Masses and Results groups, the Early-universe comparison pages, the particle map, the
  story and findings pages, the finite-results page and their data files were removed on 2026-11-17. Do not restore
  them, and do not publish a build from a source that still holds them.
- No text, table, figure or link may present a particle mass, mass ratio or the Koide relation as derived, predicted,
  reproduced or matched.
- The executable model is a calibrated test candidate, not yet a production-level model. The search for its
  specification is the current main priority.
- Publish only on top of the current `origin/gh-pages`, as a fast-forward, so that the take-down is not overwritten.
